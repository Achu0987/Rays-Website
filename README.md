# RayMindset web

Personal brand experience for Rayansh "Ray" Singh, built with Next.js (App Router, JavaScript), Tailwind CSS v4, Three.js and React Three Fiber.

## Getting started

```bash
npm install
cp .env.example .env.local
npm run dev        # http://localhost:3000
npm run lint
npm run build
```

## Docs
- `CLAUDE.md`: project instructions and owner overrides
- `docs/`: product, design, content, messaging, cloud and developer directives
- `docs/IMPLEMENTATION_PLAN.md`: sprint plan and gates
- `docs/DECISIONS.md`: decisions log and open questions

## Rules of thumb
- Only `.js` and `.jsx` files. No TypeScript.
- Never publish unverified biographical claims. Label content with a verification status.
- Every 3D scene needs a static fallback, a reduced-motion variant, and cleanup on unmount.
